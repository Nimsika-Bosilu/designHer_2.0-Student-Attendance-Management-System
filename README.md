## 🌟 Introduction

Welcome to the **designHer 2.0 Bootcamp**! Over the course of 3 exciting days, you will step into the shoes of a Full-Stack Developer. We won't just talk about theory—we are going to build a real, working web application from the ground up!

By the end of this bootcamp, you will have built a **Student Attendance Management System** complete with:
- A secure login system for teachers and admins.
- A beautiful, interactive dashboard.
- The ability to manage classrooms and students.
- A seamless interface to mark and view daily attendance.

Whether you are a complete beginner or someone looking to brush up on modern web technologies, this bootcamp is designed to be clear, simple, and incredibly rewarding.

---

## 🧠 Prerequisite Knowledge

Don't worry, you don't need to be a coding genius to take this course! We explain everything step-by-step. However, to get the most out of this bootcamp, it helps if you have:

1. **Basic Computer Literacy:** You know how to install software, create folders, and use a web browser.
2. **A Little HTML/CSS:** You know what a `<div>` is and what it means to make text bold or change a color.
3. **Familiarity with JavaScript (Bonus but not strictly required):** Knowing what a variable (`let`, `const`) or a simple function looks like will help you move faster.
4. **Enthusiasm & Patience:** Coding involves making mistakes and fixing them. Bring a positive attitude, and you'll do great!

## 💻 Computer Setup Guide

Before we start Day 1, you need to prepare your "workshop." Please install the following free tools on your computer:

### 1. Visual Studio Code (The Editor)
This is where we will write all our code. 
- 📥 **Download:** [code.visualstudio.com](https://code.visualstudio.com/)

**🧩 Useful Extensions You Already Have Installed:**
Since you already have VS Code set up, here are the extensions *currently on your computer* that will be helpful for this project:
- **VSCode Icons** (`vscode-icons-team.vscode-icons`): Adds beautiful icons to your files and folders, making it much easier to navigate our `backend` and `frontend` folders.
- **Live Server** (`ritwickdey.liveserver`): Useful if you want to quickly test simple HTML/CSS files without running a full server.
- **AI Coding Assistants** (`github.copilot-chat` / `openai.chatgpt`): Since you have these installed, they will be great helpers if you get stuck on a bug or need a React concept explained!
- **Rainbow CSV** (`mechatroner.rainbow-csv`): Helpful if you decide to export or view your MySQL database data as CSV files.

*(💡 Pro-Tip: For this specific bootcamp, you might also want to install **Tailwind CSS IntelliSense** and **Prisma** from the extension store later to make Day 2 and Day 3 much easier!)*

### 2. Node.js (The Engine)
This allows our computer to understand and run JavaScript outside of a web browser. It also gives us `npm` (Node Package Manager), which we use to download tools like React and Prisma.
- 📥 **Download:** [nodejs.org](https://nodejs.org/) (Download the "LTS" version)
- *Check if it works:* Open your computer's terminal (or command prompt) and type `node -v`. It should print a version number!

### 3. XAMPP (The Database Server)
We need a place to store our data. XAMPP gives us a local MySQL database server.
- 📥 **Download:** [apachefriends.org/download.html](https://www.apachefriends.org/download.html)
- *How to use:* Open the XAMPP Control Panel and click **"Start"** next to **MySQL**.
